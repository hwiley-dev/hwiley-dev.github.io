Featured Device

Max for Live accessibility tool

Clip Announcer

Clip Announcer reads the current clip context in Ableton Live and speaks a deterministic summary using macOS text-to-speech.

It was built for moments when visual clip highlighting and dense session layouts do not provide enough usable feedback for screen-reader-based workflows. The device speaks track, slot, and state information on demand so Session View is easier to navigate without relying on sight.

Built for

  • Blind and low-vision Ableton Live users
  • Producers who want explicit spoken feedback
  • Teachers and collaborators supporting accessible music workflows

Approach

Accessibility tooling is still a personal priority for me. I treat it as systems work: observe where feedback fails, make state legible, reduce fragile workarounds, and keep the tool close to the real workflow.

My broader research site now leads with AI safety, accessibility, and infrastructure, but this page is the landing space for people specifically looking for my access technology work.
